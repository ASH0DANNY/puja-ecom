Check `isOpen` prop is `true`\n2. Verify `order` object is not null\n3. Check browser console for errors\n4. Ensure InvoiceModal is imported\n\n### PDF Generation Fails?\n1. Verify all required invoice data exists\n2. Check browser console for error message\n3. Ensure items array is not empty\n4. Check for special characters in product names\n\n### Modal Not Closing?\n1. Check `onClose` callback is connected\n2. Verify state is being set to null\n3. Clear browser cache and reload\n\n---\n\n## 📦 Dependencies\n\n**Already installed** - No new packages needed!\n\n```json\n{\n  \"jspdf\": \"^2.x\",           // PDF generation\n  \"lucide-react\": \"^0.x\",     // Icons (Download, Eye, X, Loader)\n  \"react\": \"^18.x\",           // Hooks (useState)\n  \"typescript\": \"^5.x\"        // Type checking\n}\n```\n\n---\n\n## ✅ Verification Checklist\n\nAfter integrating:\n- [ ] Invoice button visible on orders page\n- [ ] Invoice button visible in admin dashboard\n- [ ] Modal opens when button clicked\n- [ ] Order summary displays correctly in modal\n- [ ] Preview button generates PDF (opens in new tab)\n- [ ] Download button saves PDF file\n- [ ] PDF contains all order details\n- [ ] PDF formatting looks professional\n- [ ] Error messages appear if something fails\n- [ ] Loading spinner shows during generation\n- [ ] Works on mobile devices\n- [ ] No TypeScript errors\n- [ ] No console errors\n\n---\n\n## 🚀 Deployment Steps\n\n1. **Test locally**\n   ```bash\n   npm run dev\n   # Test invoices in browser\n   ```\n\n2. **Build for production**\n   ```bash\n   npm run build\n   # Verify no errors\n   ```\n\n3. **Deploy as usual**\n   ```bash\n   # Your normal deployment process\n   ```\n\nNo special deployment steps needed -
